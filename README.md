# 🛒 Bellamart E-Commerce App

Bellamart is a basic e-commerce web application built using ASP.NET Core MVC and Entity Framework Core. The project allows users to browse products and provides a foundation for building a complete online shopping platform similar to Amazon, Nykaa, or Meesho.

---

## 🚀 Features

- Product Listing
- Product Details Page
- ASP.NET Core MVC Architecture
- Entity Framework Core Integration
- SQLite Database
- Responsive UI using Bootstrap
- MVC Pattern Implementation
- Database Migrations Support

---

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/SaimaShaikh0027/bellamart-ecommerce-app.git
```

### 2. Navigate to Project Folder

```bash
cd bellamart-ecommerce-app
```

### 3. Restore Packages

```bash
dotnet restore
```

### 4. Apply Database Migrations

```bash
dotnet ef database update
```

### 5. Run the Application

```bash
dotnet run
```

### 6. Open in Browser

```text
https://localhost:xxxx
```
